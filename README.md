# Pan-India Solar Pump Operations Dashboard

An interactive operations command center for a PM-KUSUM (Component B & C) solar pump EPC business — built as a demo of a pan-India ops view: installation pipeline, subsidy claim aging, field team performance, and after-sales SLA tracking.

Data shown is illustrative, not live.

## Run locally

```bash
npm install
npm run dev
```

## Build for deployment

```bash
npm run build
```

Outputs a static `dist/` folder — deployable to Vercel, Netlify, GitHub Pages, or any static host.
